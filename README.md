# Cafe Leads — Demo Websites

Single-page demo websites for three Kolkata cafe leads.

## Live Demos

After enabling GitHub Pages on this repo, the demos will be live at:

- **Landing page**: https://tonymaster147.github.io/cafeleads/
- **Amari Cafe**: https://tonymaster147.github.io/cafeleads/amari/
- **L'RAY Treat**: https://tonymaster147.github.io/cafeleads/lray/
- **Coffee House, New Town**: https://tonymaster147.github.io/cafeleads/coffeehouse/

## Enabling GitHub Pages

1. Go to https://github.com/tonymaster147/cafeleads/settings/pages
2. Under **Source**, select **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)` · Save
4. Wait ~1 minute, then visit the live URLs above.

## Structure

```
/index.html          → landing page with links to all three demos
/amari/index.html    → Amari Cafe site
/lray/index.html     → L'RAY Treat site
/coffeehouse/        → Coffee House, New Town site
```
